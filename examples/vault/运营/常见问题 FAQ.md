# 常见问题 FAQ

## 安装与启动

**Q：导入报 `No module named kb_engine`？**
没有把 `src` 加入路径。用 `pip install -e .` 安装，或运行时设置 `PYTHONPATH=src`。

**Q：启动提示 BGE 模型不可用？**
BGE 走本地缓存，离线环境下若从未下载过就无法使用。
此时系统会自动降级为 LSA 混合检索，服务照常可用，只是语义泛化能力弱一些。
需要 BGE 时在有网环境执行一次 `python -m kb_engine.kb_embed` 完成缓存。

**Q：MCP Server 启动报 `No module named mcp.server.mcpserver`？**
装的是 MCP SDK v1.x，代码会回退到 v1 的 `fastmcp` 路径；若仍失败，
执行 `pip install -U "mcp"` 升级即可。

## 同步与索引

**Q：`kb sync` 报"无内容可同步"？**
`vault_path` 指向的目录里没有 `.md` 文件，或路径不存在。
注意配置文件必须放在**项目根目录**，且键名不能拼错（拼错会打印警告）。

**Q：改了笔记但检索结果没变？**
需要重新同步。增量同步只处理变动文件，若怀疑索引错乱，用 `kb sync --full` 全量重建。
服务常驻时，同步后旧的检索器实例可能仍在缓存中，重启服务或等待缓存失效。

**Q：向量库能直接改吗？**
不建议。向量库是可全量重建的派生索引，永远是改源数据再重新同步。

## 检索效果

**Q：专有名词（型号、错误码）搜不到？**
纯向量通道对这类词不敏感。确认走了混合检索（BM25 通道生效），
并且建库时把文件名拼进了块文本 —— 只出现在标题里的实体靠这个召回。

**Q：语义相近的说法搜不到？**
多半是 BGE 未生效、已降级到 LSA。用 `kb eval` 看指标，或检查 `/stats` 返回的 embedding 字段。

**Q：评估指标很低？**
先跑 `kb eval`，它会列出不可达的 gold。
常见原因是评测集里的期望文件名在库中并不存在 —— 这类用例永远不可能命中。

## 自进化闭环

**Q：闭环一直回滚，从不晋升？**
先看离线闸门的判定原因。最常见的是评测集不可达导致 Hit@5 天花板过低，
其次是微调温度参数（scale）设置过小导致"训了等于没训"。

**Q：反馈记录了但不生效？**
确认 MCP 写入的反馈文件与闭环读取的是同一个文件。
两者都取自闭环配置，若手工改过其中之一就会出现飞轮断链。
