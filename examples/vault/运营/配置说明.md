# 配置说明

## 配置优先级

从高到低，后者被前者覆盖：

1. **环境变量**：`KB_` 前缀 + 配置项大写，如 `KB_API_PORT=8300`
2. **config.yaml**：项目根目录下的配置文件
3. **默认值**：`src/kb_engine/config.py` 中的 `DEFAULTS`

配置文件必须放在**项目根目录**，不是 `src/` 下。
键名拼错或 YAML 解析失败会在启动时打印警告，不会静默忽略。

## 常用配置项

### 路径

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `vault_path` | `examples/vault` | 知识源目录 |
| `chroma_path` | `data/chroma` | 向量库持久化目录 |
| `log_path` | `data/logs` | 日志与反馈落盘目录 |
| `models_dir` | `data/models` | 微调模型保存目录 |

### 集合名

| 配置项 | 默认值 |
|--------|--------|
| `collection_lsa` | `kb_lsa` |
| `collection_bge` | `kb_bge` |
| `collection_bge_candidate` | `kb_bge_candidate` |

### 模型

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `bge_model_name` | `BAAI/bge-small-zh-v1.5` | 中文嵌入模型 |
| `bge_dimensions` | `512` | BGE 向量维度 |
| `lsa_dimensions` | `384` | LSA 兜底维度 |

### 服务

| 配置项 | 默认值 | 环境变量 |
|--------|--------|---------|
| `api_host` | `127.0.0.1` | `KB_API_HOST` |
| `api_port` | `8300` | `KB_API_PORT` |

### 检索

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `top_k` | `10` | 默认返回条数 |
| `rrf_k` | `60` | RRF 融合参数 |
| `chunk_size` | `1500` | 分块大小 |
| `chunk_overlap` | `200` | 块间重叠 |

### 自进化闭环

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `closed_loop_threshold` | `8` | 触发微调的正例数阈值 |
| `dry_run` | `true` | 默认演练，不写线上状态 |
| `hit_at_5_threshold` | `0.6` | Hit@5 下限 |

闭环的详细阈值（晋升地板、回归容忍度、灰度流量、回滚线）集中在
`src/kb_engine/closed_loop_config.py`，与上面的通用配置分开管理。

## 闭环数据目录

反馈、激活状态、审计日志默认落在 `data/logs/` 下。
需要放到别处时设置环境变量：

```bash
export KB_ROOT=/path/to/kb-runtime   # 闭环数据根目录
```

## Docker 部署

容器内路径由 `docker-compose.yml` 的卷挂载决定：

```bash
docker compose up -d --build   # 构建并启动，数据在卷 kb_data 中
```

建议把 Vault 以只读方式挂载，避免容器误写源数据。
