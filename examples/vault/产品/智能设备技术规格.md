# 智能设备技术规格

## 连接方式

设备支持有线和无线两大类接入方式，现场部署时按网络条件选择：

- **无线**：Wi-Fi 2.4GHz / 5GHz 双频、蓝牙 5.0（BLE）、Zigbee 3.0 组网
- **有线**：千兆以太网（RJ45）、RS-485 工业总线
- **蜂窝**：可选配 4G Cat.1 模组，用于无局域网覆盖的户外点位

## 通信协议

| 层级 | 支持协议 | 典型用途 |
|------|---------|---------|
| 应用层 | MQTT 3.1.1 / 5.0 | 遥测上报、指令下发（默认端口 1883，TLS 为 8883） |
| 应用层 | HTTP / HTTPS RESTful | 对接第三方平台、拉取配置 |
| 应用层 | Modbus RTU / TCP | 对接工业 PLC 与传感器 |
| 传输层 | TCP、UDP、WebSocket | 实时推送场景 |
| 数据格式 | JSON（默认）、CBOR（低带宽） | 载荷编码 |

## 硬件参数

- 主控：四核 ARM Cortex-A55 @ 1.8GHz
- 内存 / 存储：2GB LPDDR4 + 16GB eMMC，支持 MicroSD 扩展至 256GB
- 供电：DC 12V/2A，支持 PoE（802.3af）可选
- 工作温度：-10℃ ~ 55℃，湿度 10% ~ 90% 无凝露

## 性能与容量

- 单机最大并发连接数：512
- 遥测上报频率：最高 10Hz，默认 1Hz
- 本地缓存：断网时可缓存 72 小时数据，恢复后自动补传

## 接口与扩展

设备对外暴露三组接口：设备影子（读写当前状态）、事件总线（订阅状态变化）、固件 OTA（远程升级）。
二次开发推荐使用官方 SDK，支持 Python、Node.js、Go 三种语言。
